# V2.0.1 中文界面与紧凑结果交互设计

日期：2026-08-26  
状态：规格复核通过，进入实施

## 目标

在不改动 V2.0.1 密码学随机、概率模型、资源预算与 GA 沙箱隔离架构的前提下，重做生成工作区的信息层级、结果中文化、明文切换、生成记录与右下角快捷操作。

本次修改覆盖 `v2.01.html` 及其 `src/v201/web/` 源文件和构建制品；`index.html`（V1.7.5）与 `index-2.0.html`（V2.0）保持不变。

## 信息架构

工作区保持三栏结构，但从英文编号改成连续的中文步骤：

1. 左栏标题为“1、选择生成类型”。分类仍为“人类凭据”“机器密钥”“标准标识符”。
2. 中栏标题为“2、策略配置”，并根据当前生成器显示“密码策略配置”“口令策略配置”“PIN 策略配置”“助记词策略配置”“Token 策略配置”“API 密钥策略配置”“Hex 策略配置”“随机字节策略配置”或“UUID 策略配置”。
3. 右栏标题为“3、生成结果”，并根据当前生成器显示相应的“密码生成结果”等名称。

左栏每个生成器按钮使用双语标签：中文居左、英文居右。按钮的选中、悬停、键盘焦点和移动端横向导航状态继续清晰可辨。英文只作为导航的辅助语言；配置、结果和说明文案以中文为主。

## 九类结果卡中文化

Password、Passphrase、PIN、Mnemonic、Token、API Secret、Hex、Random Bytes 与 UUID 的结果卡全部中文化，包括：

- 类型名称与结果编号；
- 精确生成器指标；
- 生成器最小熵、Shannon 熵、生成空间与期望猜测次数；
- 观察模式估算；
- 攻击场景估算；
- 各类型专属字段、兼容性说明与安全边界；
- 生成模型详情及其键名展示层翻译；
- 按钮、空状态、复制状态、错误与降级提示。

底层 `generationModel`、schema 字段和类型标识不改名，避免破坏测试与概率契约。UI 通过集中式中文标签映射渲染，不把显示语言写回模型。

## 默认明文与无位移切换

新生成的当前结果默认显示可渲染的明文，不再默认显示固定遮蔽符。用户可以点击“隐藏内容”，再次点击“显示内容”。

切换必须满足：

- 只原地更新目标结果的文本、状态属性与按钮文案；
- 不重新创建结果卡、不重建整个结果列表；
- 不改变结果卡、结果框与滚动容器的几何位置；
- 不触发 `scrollIntoView`、平滑滚动、入场动画或位移动画；
- 切换前后保持当前滚动位置与键盘焦点；
- 超过 DOM 渲染预算的 Random Bytes 或超长内容继续显示安全摘要，不强制渲染完整内容。

结果区说明同步改为如实表述默认明文。页面安全边界继续说明：主动生成的内容会进入当前页面 DOM，JavaScript String 无法可靠清零。

## 生成记录 History

标题改为“生成记录 History”。开关每次新页面会话仍默认关闭，不写入 `localStorage` 或 `sessionStorage`，继续受 100 条与 8 MiB 总预算限制。

启用后的记录改成紧凑单行列表：

- 每行包含类型、单行省略的结果预览、复制按钮和删除按钮；
- 结果文本使用 `white-space: nowrap` 与省略号，不扩大页面宽度；
- 点击结果预览或复制按钮会显式写入剪贴板；
- hover 或键盘聚焦时临时创建完整内容气泡，离开后立即移除；
- 气泡允许换行并受视口宽高限制，不使用永久 `title` 属性保存秘密；
- 删除单条记录会同步释放预算引用和可释放的结果数据；
- 清空记录沿用现有安全清理路径。

## 右下角快捷操作

使用 V2 原生 HTML/CSS/JS 复刻 V1.7.5 的视觉和行为，不引入 React 或 Ant Design：

- “回到顶部”：页面可滚动且滚动超过 80px 后显示；点击时使用无动画的即时滚动，避免额外位移动效；
- “GitHub”：打开仓库新标签页，显示固定 `999+` 徽标；
- “复制分享”：复制 V2.0.1 的中英文推广文案和公开网址。

分享文案不得读取当前 mode、配置、生成结果、History、URL 查询参数或 hash，不得发送网络请求。复制失败继续走现有错误提示；复制成功明确提示“已复制网站分享文案”。

移动端按钮缩为圆形图标并保留可访问名称；不得遮挡生成、复制、删除等主要操作。

## 动效策略

本次移除结果卡的入场 `reveal` 动画，以及明文显示/隐藏相关的 transform、位移和高度过渡。通用按钮可以保留颜色和阴影反馈，但显示/隐藏按钮不得产生纵向位移。`prefers-reduced-motion` 规则继续作为全局兜底。

## 安全与隐私边界

- 默认明文是用户明确要求的产品行为，因此当前结果生成后会进入可见 DOM；页面文案必须如实说明。
- 生成与复制继续分离；生成动作不得自动写入剪贴板。
- History 继续默认关闭，仅保存在当前运行内存。
- 完整记录气泡只在 hover/focus 生命周期内进入 DOM，不写入 HTML 属性或持久化存储。
- 分享功能只能复制固定公开文案，不得包含秘密或动态页面状态。
- GA sandbox iframe、固定页面字段、无 message bridge 与无 Cookie 配置保持不变。

## 响应式与可访问性

- 桌面三栏结构保持稳定；左栏双语标签使用两端对齐。
- 窄屏导航继续横向滚动，每项同时显示中英文；不得只保留难懂缩写。
- 结果与记录在 320px、390px、430px 宽度无水平溢出。
- 交互控件使用原生按钮或链接，提供中文可访问名称、键盘焦点样式和最小触控面积。
- 记录气泡支持 hover 与 focus，两种方式显示相同完整内容。

## 验收标准

自动测试至少覆盖：

1. 九类导航、配置标题、结果标题和结果卡关键字段全部中文化。
2. 新生成的 Password 默认显示明文，生成动作不自动复制。
3. 隐藏再显示时，目标结果卡与滚动容器的 bounding box、滚动位置和焦点保持不变。
4. 明文切换没有 animation、transform 或 height transition。
5. History 标题正确，记录单行省略，点击复制、删除与 hover/focus 气泡行为正确。
6. 分享文案包含 V2.0.1 公开网址，不包含生成结果 sentinel、配置、hash 或 query。
7. 回到顶部、GitHub `999+` 和复制分享在桌面与移动端可用。
8. 现有 CSPRNG、概率、边界、Clipboard、GA 隔离与真实网络泄漏测试继续通过。
9. `npm run verify:v201`、制品可复现检查、`npm audit` 和 Pages 发布门禁全部通过。

## 发布方式

修改从受保护的 `main` 派生为 `codex/` 功能分支，通过 PR 触发 `V2.0.1 security gate`。只有门禁成功后才合并并由验证后的 Pages Workflow 部署。部署后比较线上与本地 `v2.01.html` SHA-256，并检查旧版两个入口仍返回成功。
