# V1.7.5 / V2.1 右下角 X 快捷入口设计

## 目标

在 V1.7.5 归档页与 V2.1 正式页的右下角网站快捷操作中增加 X 入口，点击后在新窗口打开 `https://x.com/Betaer`。新增入口必须继承各版本现有浮动按钮的尺寸、间距、响应式行为与可访问性约定。

## 交互与顺序

- 快捷操作顺序固定为：回到顶部、GitHub、X、复制分享。
- X 入口使用链接语义，在新窗口打开，设置 `target="_blank"` 与 `rel="noopener noreferrer"`。
- 可访问名称为“在 X 关注 Betaer”。
- 不增加悬浮黑色提示或额外交互状态。

## 视觉与响应式

- 使用内联 SVG 绘制 X 标志，不引入外部图标库、字体或网络资源。
- 桌面端显示 X 图标与文本“X”。
- V2.1 继承现有 `124px` 胶囊按钮规格；V1.7.5 继承现有 `120px` 胶囊按钮规格。
- 移动端继承现有 `44 × 44px` 圆形按钮规格，只显示 X 图标，文本保留为视觉隐藏内容供辅助技术读取。
- X 按钮与 GitHub、复制分享按钮保持相同边框、背景、阴影、对齐方式和焦点样式。

## 实现边界

- V2.1 的源文件以 `src/v21/web/page.v21.html` 和 `src/v21/web/app.v21.css` 为准，通过既有构建流程更新内容哈希资产与 `index.html`。
- V1.7.5 直接更新只读归档文件 `index-v1.75.html`，沿用其 React/Ant Design 内联组件结构。
- 不修改生成器随机模型、GA 隔离策略、分享逻辑或其他页面导航。

## 验收

- 先添加失败的 HTML 契约与浏览器测试，再实现代码。
- 两个版本都必须验证链接、顺序、目标地址、新窗口安全属性和可访问名称。
- 桌面端验证与相邻按钮等宽；移动端验证按钮为 `44 × 44px` 且文字不可见。
- 运行 V1 与 V2.1 全量测试、覆盖率、构建复现及 Chromium E2E 门禁。
- 部署后在两个正式 URL 上用真实浏览器复验。

## 规格自检

- 无占位符或未决项。
- 两个版本的尺寸差异来自各自既有设计系统，不强行统一为同一像素宽度。
- 新入口仅承担外链导航职责，不增加第三方脚本执行权限。
